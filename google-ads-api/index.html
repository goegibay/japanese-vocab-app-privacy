Business and product

Kotoba Forest（言葉森林） is an independently developed consumer mobile application for learning Japanese vocabulary and preparing for the JLPT. The App uses spaced repetition, mock tests, and a forest-growing game loop. It is available as a free download with an optional VIP subscription.

Kotoba Forest advertises only its own mobile app through its own Google Ads account. The Google Ads API tool is not part of the consumer App and is not a product offered to customers.

View the Kotoba Forest product overview or view the Android app on Google Play.

API purpose and users

The proposed API client replaces repetitive manual exports from the Google Ads interface. The App owner runs a local reporting script to retrieve campaign performance, spend, conversion, and app-install reporting data, then uses the resulting internal report to make manual campaign decisions.

Only the owner/developer uses this tool. There are no customers, agency clients, public users, user accounts, external sign-in flow, public dashboard, client portal, or downstream API.

Supported operations

Operation Implementation
Reporting Read-only GoogleAdsService Search or SearchStream requests using GAQL.
Account metadata Read customer, campaign, ad group, and asset metadata needed to label internal reports.
Campaign changes No mutate methods are implemented. Campaign creation, budgets, targeting, and all other edits remain manual in the Google Ads interface.
Account scope Restricted to one advertising account owned by the applicant and linked under the applicant's manager account. The tool does not manage third-party accounts.

Data flow and safeguards

  1. The owner starts the local reporting script on an authorized computer.
  2. Google OAuth 2.0 authorizes access to the owner's Google Ads account.
  3. Read-only GAQL queries retrieve explicit reporting fields for an explicit date range.
  4. The script aggregates results into a local console or report.
  5. The owner reviews the report and makes any advertising changes manually in Google Ads.
  • OAuth refresh credentials and the developer token are stored outside source control and are never written to reports, logs, or the mobile App.
  • The tool processes aggregate advertising performance only. It does not retrieve personal identifiers, Customer Match lists, or remarketing audiences.
  • Raw responses remain in memory during a run; optional reports remain on the owner's computer.
  • Google Ads API data is not sold, shared, exposed publicly, uploaded to third-party analytics, or used to build user profiles.
